## Supplementary learning goals

- Extend the core regression examples to adjusted predictions and residual diagnostics.
- Use factor variables and distinguish categorical from continuous predictors.
- Calculate adjusted predictions with `margins`.
- Inspect residuals and recognize limits of observational models.
- Use repeated resampling to visualize sampling variation.
- Run the complete course project from the master do-file.

## Optional ungraded exercise

Run `exercise.do` from the project root with `data/derived/hotel_panel.dta`, supplied by
the instructor or generated by the preparation and analysis scripts. No earlier exercise
output is required.

Allow about 20-25 minutes. Adapt the model and resampling program in the supplementary
`lecture.do` in three ways: treat stars as categories rather than a linear predictor,
create adjusted predictions
for weekend status rather than city, and resample the **median** price rather than the mean.
Use the help files identified in `exercise.do` to find the changed syntax and stored result.

Define one sample of Hotels with positive nightly prices at most EUR 1,000, complete model
variables, and whole-star categories 1-5. Excluding half-star observations is an explicit
exercise sample choice, not a data-cleaning claim; the integer codes allow `i.stars`.
Interpret selected coefficients, check residuals, and explain the change from one star
slope to comparisons with a reference category. Adjusted predictions are on the log-price
scale. Neither the regression nor the graph establishes causal effects.

For resampling, reuse the estimation sample, draw 60 price quotes with replacement in each
of 250 repetitions, and set a fixed seed. Explain what varies across the simulated medians.
Multiple quotes can belong to one hotel: this simple quote-level resampling illustrates
variation, but it does not account for within-hotel dependence. Likewise, the regression's
robust standard errors do not address that dependence.
