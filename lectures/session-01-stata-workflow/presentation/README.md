# Session 1 introduction

[Read the course introduction slides](course-introduction.pdf).

The slides introduce the instructor, course aims, learning outcomes, assessment, and the
basics of a reproducible Stata workflow.

We start together with an empty `Introduction-to-Stata` folder and build a reproducible
project over five teaching sessions. The instructor supplies raw data as needed; students
create folders and do-files, add checks and analysis, and learn to rerun the complete
workflow. Git is not a course topic.

Session 1 is ungraded practice. Four individual checkpoints across the teaching meetings
are each worth 10% of the course score (40% in total). The final in-class exam in Session 6 is worth 60%.
A total score of 60/100 passes. Detailed exam instructions will be provided separately.
