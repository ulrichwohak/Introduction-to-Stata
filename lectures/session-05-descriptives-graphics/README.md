# Lecture 5: Automating regressions with locals and foreach

Teaching date: 12 October 2026.

Assessment: checkpoint 4 of 4, worth 10% of the overall course grade.

The existing folder name is retained for links. The core lecture is now regression
automation. The former graphics material remains as optional, ungraded reference.

## Learning goals

- Repeat a regression manually and identify the text that changes.
- Store the outcome, predictors, and cutoffs in local macros.
- Use `foreach` to repeat the same specification over price cutoffs.
- Report `e(N)` and a coefficient immediately after each model.
- Verify one iteration against a manually written regression.

## Plan for the 100-minute meeting

| Minutes | Activity |
| --- | --- |
| 0–10 | Recap the regression, observation unit, and complete sample from Lecture 4. |
| 10–25 | Repeat the model manually at nightly-price cutoffs of EUR 100, 200, and 500. |
| 25–45 | Define locals and read the expanded command before running it. |
| 45–60 | Write a foreach loop and label the reported results. |
| 60–70 | Verify one iteration manually and discuss sample sensitivity. |
| 70–95 | Individual checkpoint 4. |
| 95–100 | Recap and collect submissions. |

Run `lecture.do` from the repository root using `data/derived/hotel_panel.dta`,
supplied by the instructor or generated by the preparation and analysis scripts.
No completed exercise is needed.

In the Do-file Editor, run macro definitions together with the commands that use
them: a separate selected-block run starts a new local scope. The common-sample
rule excludes missing model variables. The price cutoffs then deliberately select
different subsets. They select on the outcome, so coefficient differences describe
sample sensitivity, not a causal effect of changing a cutoff. N counts quotes,
not unique hotels. Keep `vce(cluster hotel_id)` in every regression.

## Graded checkpoint 4

Replace continuous distance with `central_hotel`, indicating a hotel within two
miles of the center. Use locals and a loop over the three cutoffs, report N and the
central-hotel coefficient, and check one model against a manually written command.
Interpret the association and explain why the samples differ.

Submit your completed do-file and `output/logs/session05_exercise.log`.
Consult `help local`, `help foreach`, `help regress`, and `help fvvarlist`.
The exercise contains TODO prompts, not solutions.
